# Data Structures and Algorithms

## Set

A set stores distinct elements without any duplicate entries.<br>It is used to efficiently check if elements are part of a set (membership).<br>Elements cannot be retrieved using indices (not like arrays, where array[1] = element).

**Space complexity:** O(n)

A set is similar to an array in that it can be created, added to, or removed from, emptied, and checked for its size or if it contains a certain element.

The time complexity of these operations depends on the implementation of the data structure by different programming languages.

## Stack

A stack uses the last-in first-out (LIFO) principle to store objects.<br>Pushing an object onto the stack adds it to the 'top' of the stack while popping from the stack removes the object at the 'top' of it.<br>Stacks are usually initialised as arrays or lists in programming, where the operations take **O(1)** time to perform.
